# inventory_supply_chain
This project focuses on analyzing inventory and supply chain data using Power BI to help businesses monitor stock levels, supplier performance, and product movement efficiently. The dashboard provides clear and interactive visual insights that support better inventory planning, demand forecasting, and decision-making.

## Objectives

- Track inventory levels across products and categories
- Analyze supply chain performance and stock movement
- Identify low-stock and over-stock situations
- Improve operational efficiency through data-driven insights

## Key Features

- Interactive Power BI Dashboard
- KPIs for:
  - Total Inventory
  - Stock In / Stock Out
  - Product Availability
  - Supplier Performance
- Category-wise and product-wise analysis
- Trend analysis using charts and slicers
- User-friendly filters for dynamic data exploration

## Insights Gained

- Identified products with frequent stock shortages
- Analyzed supplier contribution and delivery efficiency
- Improved understanding of inventory turnover trends

## Conclusion

This project demonstrates how Power BI can be used to convert raw inventory data into meaningful visual insights. It is especially useful for beginners and data analyst freshers to understand dashboard design, KPI creation, and business analysis.
